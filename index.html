5 Framework dari Satu Sumber

Paket terpisah dan idiomatik untuk React, Vue 3, Svelte, Vue 2, dan Angular (@komerce-design/*) dengan perilaku dan tampilan identik.

Headless Controllers & Engine

Gunakan komponen UI siap pakai, hubungkan createFormController / createTableController / createOverlayController, atau bangun custom UI sendiri dengan getChart*State & primitif SVG.

Semantic Design Tokens & Dark Mode

Token warna, sub-brand Komerce, tipografi, radius, dan shadow diekstrak langsung dari Figma ke CSS variables & Tailwind v4 (@komerce-design/tokens).

Local-First Figma Pipeline

Untuk kontributor design system, tersedia CLI lokal (`pnpm komerce sync`, `regen`, `build`) dan Figma plugin tanpa ketergantungan server atau database.
