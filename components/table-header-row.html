TableHeaderRow ​

Description A reusable table header row with up to ten configurable columns.

When to use Use at the top of a data table to label and align its columns. Omit it only when the surrounding context makes every column unambiguous.

Usage guidelines Match visible header columns to the visible columns in every body row. Use short, descriptive labels. Keep column order and widths consistent with the body rows. Avoid wrapping header labels when a shorter label is available.

Properties Show Column 1–10 — Shows or hides each header column. Columns 1–5 are visible by default; columns 6–10 are optional.
