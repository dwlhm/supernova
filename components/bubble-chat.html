BubbleChat ​

Bubble Chat displays a message inside a conversation thread. It supports incoming and outgoing messages with text, file, image, or video content, including delivery-error states.

WHEN TO USE • Use in chat, support, inbox, messaging, and collaboration experiences. • Use Incoming for messages received from another participant. • Use Outgoing for messages created by the current user. • Use attachment types only when the message contains the corresponding media. • Use Error only when sending or uploading has failed.

USAGE GUIDELINES • Keep message copy concise and conversational. • Choose the Type that matches the primary content. • Keep timestamps consistent within a conversation. • Show delivery status only when it provides useful feedback. • Use Custom text for optional supporting information, not the primary message. • Error messages should explain the failure and, when possible, support a retry action nearby.

PROPERTIES • Direction: Incoming | Outgoing • Type: Text | File | Image | Video • State: Default | Error • Show time: Shows or hides the timestamp. • Show status: Shows or hides delivery status in Default state. • Show custom text: Shows or hides supplementary copy. • Editable text properties: Custom text, Text message, File name, File metadata, Image name, Image metadata, Video name, Video metadata, Incoming status text, Outgoing status text, Error status text, Incoming time text, Outgoing time text.
