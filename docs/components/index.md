# Components Overview

Browse the multi-framework components generated from Figma.

## Component Catalog

- [AlertDialog](./alert-dialog.md) — Alert dialog asks users to explicitly confirm an important, risky, or difficult-to-reverse action before it is performed.
- [Avatar](./avatar.md) — A circular identity component used to represent a person, account, or entity. It supports profile images, initials, and a generic icon fallback across five sizes, with an optional presence indicator.
- [Badge](./badge.md) — A compact label used to communicate status, category, or supporting metadata without interrupting the main content.
- [Breadcrumb](./breadcrumb.md) — Description
- [BubbleChat](./bubble-chat.md) — Bubble Chat displays a message inside a conversation thread. It supports incoming and outgoing messages with text, file, image, or video content, including delivery-error states.
- [Button](./button.md) — A versatile interactive component for user actions and link-styled navigation. It supports multiple emphasis levels, sizes, corner treatments, interaction states, optional leading and trailing icons, and an editable label.
- [Chart](./chart.md) — Chart is a flexible data-visualization component with 12 variants for comparing values, revealing trends, showing composition, and communicating progress.
- [Checkbox](./checkbox.md) — A checkbox lets users select or clear one or more independent options. It supports selected and unselected states, three sizes, disabled states, and optional labels on either side.
- [DatePicker](./date-picker.md) — A date-selection component for choosing a single date, a date and time, a date range, a year, or a date expressed in natural language.
- [FAB](./fab.md) — Floating Action Button (FAB)
- [IconPlaceholder](./icon-placeholder.md) — Placeholder icon used as the default content for an instance-swap icon property.
- [InputDropdown](./input-dropdown.md) — A selection input that lets users choose one option from a predefined list while keeping the form compact.
- [InputFileDropZone](./input-file-drop-zone.md) — A large upload target for adding a file by drag and drop or by opening the device file picker.
- [InputFileInput](./input-file-input.md) — A compact file input that lets users browse for and select a single file from their device.
- [InputImageUploader](./input-image-uploader.md) — An image-specific uploader for selecting or dropping an image and communicating its preview or upload status.
- [InputMultipleFileUpload](./input-multiple-file-upload.md) — A multi-file upload input for adding and managing several files in one interaction.
- [InputOTP](./input-otp.md) — A one-time password input for entering short verification or authentication codes.
- [InputText](./input-text.md) — A single-line input for collecting short-form information such as names, titles, email addresses, search terms, or other concise values.
- [InputTextArea](./input-text-area.md) — A multi-line text input for collecting longer free-form content such as messages, comments, notes, feedback, or descriptions.
- [MainMenu](./main-menu.md) — A primary navigation item used for top-level destinations in the sidebar. It supports interaction and selection states, optional leading and trailing icons, and an optional status badge.
- [MenuItem](./menu-item.md) — A secondary or expandable navigation item used within a menu hierarchy. It supports optional icons and badges, plus a submenu content slot for nested destinations.
- [MetricCard](./metric-card.md) — Overview
- [Pagination](./pagination.md) — Description
- [Progressbar](./progressbar.md) — A horizontal progress bar that communicates how much of an ongoing process has been completed.
- [RadioButton](./radio-button.md) — Description
- [Sidebar](./sidebar.md) — A persistent vertical navigation shell that organizes brand, primary navigation, and account-related content. It supports expanded and collapsed layouts so the navigation can adapt to the available workspace.
- [Slider](./slider.md) — A slider allows users to select a single value from a defined range by moving a thumb along a track. The filled bar communicates the current value relative to the available range.
- [Spinner](./spinner.md) — Spinner
- [Stepper](./stepper.md) — Description
- [SwitchButton](./switch-button.md) — Description
- [TabItem](./tab-item.md) — A single tab item used inside the Tabs component. It supports a text label, an optional leading icon, an optional numeric value, and Default or Active states.
- [Table](./table.md) — Description
- [TableBodyCell](./table-body-cell.md) — Description
- [TableBodyRow](./table-body-row.md) — Description
- [TableCellValue](./table-cell-value.md) — Description
- [TableCheckboxBodyCell](./table-checkbox-body-cell.md) — Description
- [TableCheckboxHeaderCell](./table-checkbox-header-cell.md) — Description
- [TableHeaderRow](./table-header-row.md) — Description
- [TableNoBodyCell](./table-no-body-cell.md) — Description
- [TableNoHeaderCell](./table-no-header-cell.md) — Description
- [Tabs](./tabs.md) — A horizontal tab bar composed of Tab Item instances. It provides up to eight tabs for switching between related content views or categories.
- [Toast](./toast.md) — A brief, non-intrusive notification that communicates the status of an action or process without interrupting the user’s workflow.
- [Toggle](./toggle.md) — Toggle lets users switch a single setting between off and on, with the change taking effect immediately.
- [ToggleGroup](./toggle-group.md) — Description
- [Tooltip](./tooltip.md) — Tooltip provides brief contextual information about a UI element without interrupting the user’s workflow.
- [Topbar](./topbar.md) — A horizontal application header that provides a consistent area for page-level or global controls through a flexible content slot.
