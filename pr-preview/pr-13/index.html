Architecture

Whole Document Extraction

Custom Figma plugin using loadAllPagesAsync() traverses every page, collecting design tokens (variables, paint styles, text styles) and component sets.

Hexagonal Go Orchestrator

Clean Ports & Adapters architecture isolating domain logic from HTTP, filesystem, subprocesses, and AI providers.

LLM Mitosis Authoring & Repair Loop

OpenAI-compatible authoring client (Ollama, OpenAI, vLLM) with structured output and automated compiler feedback repair loop.

5 Target Frameworks

Compiles single-source Mitosis .lite.tsx components simultaneously to React, Svelte, Vue 3, Vue 2, and Angular.

Dual Publishers

Download complete multi-framework zip bundles directly from the plugin or create automated GitHub Pull Requests.
